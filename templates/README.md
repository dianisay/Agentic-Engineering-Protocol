# Template map

Copy only the records needed for the approved work into an authorized output
location. Fill missing values with an explicit reason, not an implied approval
or pass. The linked protocol defines requirements; templates capture them.

| Stage or record | Template | Authoritative guidance |
|---|---|---|
| Discovery | [Audit report](audit-report.md) | [01 audit](../protocol/01-audit.md) |
| Portfolio | [Projects overview](projects-overview.md), [master plan](master-plan.md) | [02 planning](../protocol/02-portfolio-planning.md) |
| Routing | [Session routing plan](session-routing-plan.md) | [03 routing](../protocol/03-session-routing.md) |
| Activation | [Worker contract](worker-contract.md) | [04 activation](../protocol/04-session-activation.md) |
| Human authorization | [Approval record](approval-record.md) | [01 authority rules](../protocol/01-audit.md#common-authority-and-ownership-rules) |
| Dependency communication | [Message record](message-record.md) | [05 communication](../protocol/05-inter-agent-communication.md) |
| Claims and evidence | [Evidence manifest](evidence-manifest.md) | [01 claim contract](../protocol/01-audit.md#common-evidence-and-claim-contract) |
| Advisory review | [Critic review](critic-review.md) | [02 planning](../protocol/02-portfolio-planning.md) |
| Acceptance checks | [Validation report](validation-report.md) | [07 validation](../protocol/07-validation.md) |

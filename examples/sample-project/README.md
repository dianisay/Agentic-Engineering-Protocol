# Fictional sample: documentation search

This example has no real sessions, files, users, or measured results. It
illustrates a small project to make a product manual searchable by topic.
The owner permits planning and local, isolated tests, but retains approval for
publication and external sharing.

Read [the audit](sample-audit.md) and [the plan](sample-plan.md), then follow the
fictional continuation below. Copy the relevant templates into an approved
output directory for real work. With a compatible host,
discover whether existing sessions are usable before creating anything. Without
one, a person can maintain the same records and relay handoffs manually.

Example request:

> Audit the documentation-search project in the approved workspace. Inventory
> existing artifacts and sessions without changing them, then propose a plan
> that measures search relevance and documents failed approaches. Do not
> publish or access external services without approval.

The protocol does not guarantee that the fictional acceptance thresholds are
appropriate for a real project.

## Full lifecycle reading order

1. [Audit](sample-audit.md): unknown capabilities and missing acceptance judgments.
2. [Plan](sample-plan.md): proposed prerequisites and gate, not execution authority.
3. [Contract](sample-contract.md): imagined resolved prerequisites, scoped
   approval, frozen gate, ownership, budget and activation handshake.
4. [Dependency message](sample-message.md): manual request, receipt, bounded
   acknowledgement and deduplication without transferring authority.
5. [Validation](sample-validation.md): invented v1 failure, retained findings,
   one authorized revision and illustrative v2 local acceptance.
6. [Handoff](sample-handoff.md): resource reconciliation, quiescence distinction,
   residual risks and a separate publication decision.

The continuation assumes the owner resolved the audit's unknowns; it is not
evidence that those prerequisites exist. Candidate/dataset/log identifiers and
all counts, times, approvals and outcomes are invented. No fixture executes
this narrative, and its illustrative PASS outcomes must not be reused as real
`CONFIRMED` evidence.
